# Lista zakupów

Aplikacja mobilna na iOS (Swift, SwiftUI, SwiftData) do tworzenia list zakupów.

## Funkcje (w trakcie realizacji)

- wiele list zakupów,
- produkty z kategoriami (domyślnymi i własnymi),
- oznaczanie produktów jako kupione,
- lokalna baza danych SwiftData.

## Wymagania

- Xcode (najnowsza wersja),
- iOS 17 lub nowszy.
